MIDI Voyager Windows 1.1

A clean-room Windows edition built for fast local MIDI playback and visualisation. Audio synthesis runs off the interface thread and uses the included GeneralUser GS SoundFont.

Supports MIDI formats 0, 1 and 2, KAR lyrics, RMIDI/XMF parsing, SF2/SF3/DLS sound banks, GS/XG messages, Web MIDI input/output and offline WAV rendering.
